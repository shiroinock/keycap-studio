# Keycap Studio

キーキャップセットのデザイン案を継続的に作成し、実際の配列上で比較・改善するためのツール。

**現在の状態：企画・リポジトリ準備段階。アプリはまだ実装されていません。**

## 目指す体験

コンセプトを入力 → 配色・レジェンド・Noveltyを編集 → キーボード上で確認 → 複数案を比較 → 保存 → SVG/PNG出力。

日本発のキーキャップセットを継続的にデザインし、将来的にはIC（需要調査）やメーカーとの製品化に発展させることを目指します。

## MVP

- コンセプト、配色、レジェンド、Novelty、対応配列を構造化データとして管理する。
- 標準ANSI 60%（61キー）を最初の配列とし、キーの位置・サイズ・文字をSVGで正確に描画する。
- 手動で案を作成・複製・編集し、複数案を並べて比較する。
- 案をブラウザに保存して再編集できるようにする。
- SVG/PNGと、バックアップ用のJSONを出力する。JSONから復元できるようにする。

生成画像を完成図として使わず、同じ入力から同じ結果が得られるSVGレンダラーを使います。AI生成・週次自動生成・クラウド同期・製造発注はMVPに含めません。

## 前提

- JIS、HHKB、40s、moNa2、roBaなどは、正確な配列資料を確認して段階的に追加する。
- SVG/PNGはデザイン検討用。画面上の色と製造色の一致や、メーカーへの入稿適合を保証しない。
- MOQ、単価、製法の条件は未確定。見積もり取得前の数字を製造原価として扱わない。
- privateリポジトリとして開始し、公開やライセンスは別途判断する。
