# Keycap Studio

キーキャップセットのデザイン案を、実際の配列上で作成・比較・保存するローカルWebアプリ。

**M1〜M4.1a＋KLE配列インポートを実装済み。** 2D編集とReact Three Fiberの3Dプレビューをローカルで利用できます。Blender連携は次の段階です。

## 起動

Node.js 22.12以降（Node 22推奨）とnpmが必要です。

```sh
npm ci
npm run dev
```

[http://127.0.0.1:5173](http://127.0.0.1:5173) をブラウザで開きます。停止はターミナルでCtrl+C。サーバーはループバックのみに接続し、ポート5173が使用中の場合はエラーにします。別ポートを使うとブラウザ保存先も変わります。

## できること

- ANSI 60%・61キー、およびKLEから取り込んだ配列のSVG／3Dプレビュー。
- 行別の高さ・傾斜を持つ3Dプレビュー、回転・拡大、上面／斜め、照明3種＋ニュートラル／陰影なし色確認・質感2種。
- 3Dでも日本語・Novelty・配色編集を反映。2〜4案の視点を同期し、現在の視点でPNG出力。
- 新しい案の作成、複製、名前・ストーリー・キーワードの編集。
- アルファ／モディファイア／アクセントのキー色・文字色、キー色のHEX入力。
- 各キーのメイン／サブ文字、色の役割、個別色、Novelty（太陽・月・星・波）。
- 文字の左寄せ／中央、サブレジェンドの表示切替。
- 同じ配列の2〜4案の同倍率比較、お気に入り、検索。
- ブラウザ内自動保存、JSONバックアップ／読み込み。
- SVG、PNG（幅1896・2844・3792px）の生成と出力プレビュー。ダイアログの「ファイルを保存」でダウンロード。

初回はTidal Notes / After Hours / Lunar Archiveの3案が入っています。周囲のUIは白・グレー・チャコールを基本にし、操作のアクセントだけオレンジを使います。

## 基本の操作

1. 「新しいスタディ」または「案を複製」で始める。いずれも現在の配列を使う。別配列は「KLE配列を読み込む」から追加する。
2. 配色とコンセプトを編集。キーをクリック、または「選択中のキー」で選んで文字やNoveltyを変える。
3. 「並べて比較」で候補を選ぶ。気に入った案は星を付ける。
4. 「このブラウザに保存済み」を確認。再読み込み後はライブラリから案を選び直す。
5. SVG/PNGを生成し、プレビューを確認して保存する。
6. 大切な案は「JSONバックアップ」からファイルを保存する。

## 配列プリセット

「プレビュー配列」で同じデザインの配列を切り替えます。「配列の一覧」では形状を確認してから切り替えられます。

| 配列 | キー数 | 主な仕様 |
| --- | ---: | --- |
| ANSI 60% | 61 | 6.25uスペース、既存ANSI配列 |
| ANSI 65% | 68 | 6.25uスペース、隙間なし |
| ANSI 75% | 84 | F列あり、隙間なし |
| ANSI TKL | 87 | 独立した矢印・ナビゲーション |
| ANSI 96% | 100 | テンキー一体型 |
| ANSI フルサイズ | 104 | 独立したテンキー |
| HHKB US 6u | 60 | 6uスペース、HHKB英語配列 |
| JIS 60% / TKL / フルサイズ | 65 / 91 / 109 | L字Enter、3.75u / 3.75u / 3.25uスペース |
| ISO UK 60% / TKL / フルサイズ | 62 / 88 / 105 | L字Enter、6.25uスペース |
| HHKB型 7u | 60 | 7uスペース、両端ブロッカー |
| テンキー | 17 | 縦長の＋／Enter、2uの0 |
| 格子4×12 / 5×12 / 10×10 | 48 / 60 / 100 | 全キー1u |

各サイズの代表的な一例で、全機種を網羅するものではありません。HHKB型7uはカスタムキーボード向けの形状で、HHKB製品の6u配列とは異なります。刻印は編集用の初期値で、ファームウェアの割り当てを定義しません。JIS・ISOのL字Enterにも対応しています。Aliceなどの回転キーは今後の対応範囲です。

参照元と形状の選定は[プリセット資料](docs/layout-presets.md)を参照。プリセットで作った案も既存の比較・画像出力・保存・JSON復元を利用できます。

## KLE配列の取り込み

「KLE配列を読み込む」でファイルを選択、またはJSONを貼り付け、「配列を確認」でキー数・形状を確認して案を作ります。[Keyboard Layout Editor](https://www.keyboard-layout-editor.com/) のDownload JSON形式に対応します。Raw data欄の省略記法・JSON5には未対応です。

- 1〜200キー、全体40×20u以内、各キー幅・高さ0.5〜10u、19.05mmピッチ。行のずれ、空白、長方形の縦長キーとJIS/ISOのL字Enterを扱えます。
- 回転、対応Enter以外の非長方形、重なり、デカール、ゴースト、段付き形状、突起、側面レジェンドは理由を表示して拒否します。
- 上面の文字は最大2つ。2つある場合は上側をサブ、下側をメインとして取り込みます。KLEの色・書式・文字配置・プロファイル指定は取り込まず、現在の案のパレットを使います。
- 3Dの行形状は正規化した縦位置から0〜4へ割り当てます。実際の製品プロファイルの指定ではありません。
- 配列は案に埋め込み、保存・JSON復元時も保持します。比較候補は同じキーID・位置・サイズ・行形状の案に限定します。
- 2D PNGは配列に合わせた縦横比。高さ8192pxまたは1600万画素を超える場合は縦横比を保って縮小します。
- KLE入力は200KBまで。自由な配列編集・既存案の別配列への移し替えは未対応です。

試用データ：[6キーのマクロパッド](examples/kle/macropad.json) / [10×10のグリッド](examples/kle/grid-100.json)。グリッド例は読み込み確認用で、特定の製品や設計データを表すものではありません。

## 保存と復元

- 保存先はlocalStorageの `keycap-studio.library.v2`。ブラウザとURLのオリジンごとに別です。`localhost` と `127.0.0.1` のデータも別になります。
- v2がない場合は旧v1保存を読み込み、v2へ保存します。旧v1データは削除しません。JSONバックアップは配列を含むv2形式で、旧v1のANSI案も引き続き読み込めます。
- 最大200案。JSON入力は2MBまで。外部サーバーへの送信、ログイン、クラウド同期はありません。
- 読み込みは既存ライブラリへの**追加**です。同じIDは新IDのコピーとして追加し、既存の案を上書きしません。
- 不正JSON、未対応バージョン、重複ID、不正色、存在しないキー参照は拒否します。
- 既存の保存データを読み込めない場合は自動保存を止め、元データの退避操作を表示します。容量不足などで書き込みに失敗した場合も未保存と表示します。
- ブラウザのデータ消去やプライベートモード終了で案が失われることがあります。JSONを別途保管してください。
- 複数タブでの同時編集・競合解決は未対応です。編集は1タブで行ってください。

## フォントと出力の制約

2D出力と3D上面テクスチャは共通のレジェンド描画を利用し、日本語は端末のHiragino / Yu Gothic / Noto Sans JP等を使用します。フォントの配布・埋め込みは行いません。SVGの字形は表示端末によって変わり得るため、見た目を固定して共有する場合はPNGを使ってください。

空欄のレジェンドも保存可能です。長い文字列はキー幅に合わせて縮小します。Noveltyは文字の代わりに表示します。

生成画像はデザイン検討用です。製造色、キーキャップの物理的なプロファイル、メーカー入稿適合を保証するものではありません。MOQ・単価・製法の条件は見積もりで別途確認します。

## 実装構成

- `src/domain/`：ANSI配列、KLE変換、バージョン付きデータ、Zod検証、サンプル、共通キー表現。
- `src/renderer/`：決定論的なSVGとPNG出力。
- `src/storage/`：JSONの保存・復元。
- `src/components/`：プレビュー、色入力、入出力ダイアログ。
- `src/App.tsx`：編集・比較・ライブラリ操作。

共通キー表現には安定したID、u単位の幾何情報、行指定、色・文字・Noveltyを持たせています。物理ピッチは配列に保持し、3Dレンダラーもこの共通データを使います。

## 3Dの範囲

「3D」で切り替え、ドラッグで回転、スクロールまたは＋／−で拡大します。比較画面は1案を回すと全案が追従します。3D PNGは灰色背景、幅1896・2844・3792px、縦横比2.2です。SVGは常に2Dです。カメラ・照明はセッション中の表示設定でJSONには保存しません。

Studio Sculpted v2は独自の検討用概形です。メーカーの実測形状やCherry互換CADではなく、ステム・裏面・製造肉厚は含みません。3DにはWebGLが必要です。利用できない場合は「2D」で編集・保存を続けられます。

### 写真に近いプレビュー

3Dの「斜め」は遠近感のある写真カメラ、「上面」は比較しやすい平行投影です。「カメラ」で投影方式を切り替えられます。照明・質感・カメラは比較中の全案で共通です。

キーの上端を丸め、くぼみの反射を滑らかにしました。ローカル生成のスタジオ環境光、細かな樹脂の凹凸、柔らかい接地影を使います。マットは落ち着いた反射、サテンはやや滑らかな反射です。PNGにも同じ形状・材質・照明を適用します。外部HDRIのダウンロードや追加サーバーは不要です。

影や反射はリアルタイム向けの近似です。実物のPBT／ABSを測定した材質ではなく、Blenderのパストレーシングと同等の間接光計算は行いません。大きく回転・拡大して見切れた場合は「斜め」か「上面」で構図を戻せます。

### 色の確認

パレットと2Dは指定したHEXのsRGB色を表示します。2Dのキーには明るさを変えるハイライトを重ねません。3Dの「照明 → 色確認（陰影なし）」は照明・反射・トーン補正・フォグを適用せず、同じ指定色でキーと文字を表示します。この間は質感の選択を無効にします。「スタジオ」などに戻すと通常の陰影と質感に戻ります。色確認設定は比較画面とPNGにも反映します。

個別キーに指定した色は役割ごとのパレットより優先されます。

3Dの初期照明は「ニュートラル（色確認）」です。白色の環境光と斜めからの光で弱い陰影を付け、色調補正と反射を省きます。陰影による明るさの差は残ります。HEX値そのものの確認には「色確認（陰影なし）」を使います。ニュートラルでも質感の選択は無効になります。

## 同じセットで配列・プロファイルを切り替える

プレビュー上部の「プレビュー配列」で同じデザインを切り替えます。案の名前・配色・共通キーの編集は保持し、表示されないキーの編集も復帰時に戻ります。KLE配列も同じデザインへ追加でき、選択肢に残ります。「新しいスタディ」「案を複製」で別デザインを作れます。

共通キーは元の刻印と同名キーの出現順で照合します。メイン部とテンキーは分離、スペースは幅をまたいで共有。格子配列と無刻印の独自キーは配列ごとに保持します。別名の独自キーや特殊な重複キーを自動で同一視する機能はありません。

「プロファイル」はDSA・XDA・OEM・Cherry・SA等の市販29種類。3D形状とPNGに反映し、デザインと一緒に保存します。公開資料を参考にした概形で、正確な製品CADではありません。[参照元と再現範囲](docs/keycap-profiles.md)を記録しています。

「R・uバリエーション」では、このデザインで確認した配列に必要な幅・高さ・行・形状を集計。現在の使用数と各配列での最大使用数を表示します。R表記はプロファイル別、共通行はR0、スペースは専用形状。配列側の必要数を確認するための表です。

配列切り替え後はschemaVersion 3で共有キー・確認済み配列を保存します。v1/v2はそのまま読み込めます。以前のアプリ版ではv3データを読み込めません。


## セット展開図・収録キーの編集

「セット展開図」タブは、ANSI 104キーを土台に、JISで用途・R・寸法・形状が異なるキーだけを実配列の座標に沿って下へ並べます。左端と縮尺を揃え、共通キーは1回だけ表示します。差分の空欄は共通キーを使用する位置です。未収録キーはグレーで示し、クリックして追加できます。どちらにも使われないサイズ・行違い・ノベルティは下に残します。この配置を「収録キー一覧（すべて）」に統合しています。各キットでの絞り込みもできます。2Dと陰影付き3Dを切り替え、キーをクリックすると刻印・色・R・幅・収録数を編集できます。表示キットの絞り込み、SVGと3D PNGの書き出しにも対応します。

収録キーはプレビュー配列と独立しています。既存案は最初の配列を初期セットとし、配列切り替えで自動的に増えません。「不足分をセットに追加」で現在の配列の不足分を追加できます。「＋ キーを追加」では元キーまたは独自キーを指定し、R・幅・高さ・形状・数量を選べます。ノベルティとして複製して色違いを作ることもできます。

同じ種類は1枚で描画し、2個以上は2D図に数量を表示します。収録キー独自の配色・刻印は通常の配列プレビューにも反映します。同じ用途・R・寸法の色違いが複数ある場合、初期状態では配列プレビューに先頭の収録キーを使用します。「キーをカスタマイズ → この配列で使用する収録キー」で、色見本や選択欄からバリエーションを指定できます。選択は配列ごとに保存し、JSON・案の複製にも含みます。選択したキーの幅・Rが変わったり削除された場合は自動選択へ戻ります。明示的に選択した候補の色・刻印を編集すると、その収録キー自体に反映します。収録判定は用途・R・寸法・形状・数量によるもので、実メーカーの金型・軸・スタビライザー互換を保証するものではありません。

収録内容はブラウザ保存・JSON・案の複製に含まれます。「セットから除外」や追加・編集の直前の状態は「収録キーの変更を戻す」で1回戻せます。

### 対応配列一覧

セット展開図の「対応配列」で、プリセットと読み込み済み配列の収録数・必要数・不足を一覧できます。詳細にはキー用途、R、幅・高さ、形状、数量を表示。キー単位・配列単位・選択した複数配列の不足分を追加できます。複数配列の共通不足は最大必要数だけを補い、追加後はその場で再判定します。「収録キーの変更を戻す」で直前の追加を戻せます。確認・追加でプレビュー配列は変わりません。

### 対応したい配列から構成案を生成

「対応配列」で対象を選択して「構成案を確認」を押すと、共通・ベース／配列ごとの差分／テンキーの必要キーを集計します。必要数、既存から使う数、追加数、そのほかに保持する数を確認し、「構成案を適用」で不足分と対象配列を保存します。追加キーは共通部分をベース、配列差分を追加キー、テンキーをテンキーへ分類します。既存キーのグループ・配色・ノベルティは変えません。選択を減らしても既存キーは削除せず、必要数を再計算します。

### セットの削除

画面上部の「セットを削除」で選択中のセットを削除できます。「削除を取り消す」で直前から順番に復元できます。取り消し履歴はページの再読み込みまで保持します。最後のセットも削除でき、空の状態をブラウザに保存します。
