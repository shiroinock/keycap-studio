# キーキャップセット作成のUI

## 想定する作業

1. 対応させたい配列とプロファイルを決め、必要なキー構成を作る。
2. 共通パレットを調整し、修飾キーやアクセントをまとめて配色する。
3. 特定キーの刻印や絵柄を作り、必要ならサイズ違い・色違いを追加する。
4. 対象配列に装着した姿を確認し、修正のためデザインへ戻る。
5. 画像を出力し、再編集できるJSONを保存する。

## 工程ごとの画面

- 構成：セット名・プロファイル・対応配列・必要数・構成案の適用。新規作成は空のキットから開始。KLE追加等の配列操作もここへ集約。
- デザイン：展開図を中央、共通パレットと選択キーを右側へ配置。1種類の選択では個別編集、複数選択では一括編集。セットの説明、キーの仕様、絵柄、詳細な収録状況は折りたたむ。狭い画面では編集欄を下へ送る。
- 確認・出力：装着イメージ／展開図を選び、2D/3Dと視点・照明を確認。配列ごとの使用バリエーションも確認できる。通常の色・刻印編集は表示せず、画像とセット単位のJSONを出力する。

工程は自由に往復でき、進行を強制しない。同じセット内で選択と収録キーUndoを保持する。新規セットのみ構成から開始し、既存セットの選択・複製はデザインから開始する。

## 整理した操作

比較機能は復活させない。セット削除・複製は操作メニューへ、説明文は折りたたみへ、画像出力は最終工程へ移動。既存のセットや保存形式を移行・削除しない。
