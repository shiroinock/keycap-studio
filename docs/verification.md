2026-09-27 / ローカル開発サーバー、macOS、Codex内蔵ブラウザ。

## 自動検証

`npm test` / `npm run build` を実行。11テストで以下を検証。

- ANSI 60%は61キー、各行の数は14/14/13/12/8、全行15u。隣接キーの座標、Enter 2.25u、Space 6.25u。
- 不正寸法、非有限値、キーIDの重複を拒否。
- 日本語、キー上書き、色、NoveltyのJSON往復。
- 未対応バージョン、不正JSON、重複ID、不正色、不明配列・キー参照、空のライブラリを拒否。
- 複製・インポートで元のデータを変更しない。
- 同一入力から同じSVG、61キーの生成とEnter位置。
- マークアップのエスケープ、長いレジェンドの幅制限、不正なXML文字の置換。
- 保存容量・読み込み権限のエラー伝播。破損データを読む際に書き込みをしない。

## 検証範囲の限界

- 内蔵ブラウザではダウンロードイベントを取得できなかったため、OSの保存先にファイルが作られたことは未確認。出力データ、保存用リンク（MIME・download属性）、画像プレビュー、JSON内容を確認済み。通常のブラウザで「ファイルを保存」を使う。
- デスクトップの複数ブラウザ・複数OSの網羅テストは未実施。
- フォントはシステムフォント参照で、SVGの別端末での字形一致は保証しない。
- 当初のMVP検証ではBlender、複数配列、複数タブ同時編集は対象外。KLE配列の追加検証は下記。
