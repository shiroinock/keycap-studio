# 2D MVPの検証

2026-09-27 / ローカル開発サーバー、macOS、Codex内蔵ブラウザ。

## 自動検証

`npm test` / `npm run build` を実行。11テストで以下を検証。

- ANSI 60%は61キー、各行の数は14/14/13/12/8、全行15u。隣接キーの座標、Enter 2.25u、Space 6.25u。
- 不正寸法、非有限値、キーIDの重複を拒否。
- 日本語、キー上書き、色、NoveltyのJSON往復。
- 未対応バージョン、不正JSON、重複ID、不正色、不明配列・キー参照、空のライブラリを拒否。
- 複製・インポートで元のデータを変更しない。
- 同一入力から同じSVG、61キーの生成とEnter位置。
- マークアップのエスケープ、長いレジェンドの幅制限、不正なXML文字の置換。
- 保存容量・読み込み権限のエラー伝播。破損データを読む際に書き込みをしない。

## 実ブラウザ確認

- 新しい案「喫茶の余韻」を作成し、コンセプト・キーワード・HEX配色を編集。
- キー選択、Enterのメイン文字「喫茶」・サブ文字「温」、Escapeの太陽Noveltyを編集。
- 複製案の配色変更が元案を変えないことを確認。お気に入りを保存。
- 4案を並べて表示し、5案目の選択が無効になることを確認。
- 再読み込み後に案を選び、名前・日本語・色指定を照合。
- 不正なschemaVersionのJSONをファイル選択で読み込み、拒否メッセージと既存案の保持を確認。
- 出力JSONの案を読み込み、既存IDは「（読込）」付きの別コピーになることを確認。
- 保存領域が異なる `localhost:5173` の初期ライブラリへ同じ案を読み込み、名前・日本語・色を照合。
- SVGの出力データで61個のキー、日本語、指定色を確認し、出力プレビューを目視確認。
- PNG出力プレビューで日本語・Noveltyを目視確認。3792px設定のPNGバイナリを読み、3792×1392pxであることを確認。
- 390px幅でフォーム編集を実行。画面幅に応じて編集カード・比較カードを1列に表示。
- 検証時のブラウザエラーログにアプリのエラーなし。

## 検証範囲の限界

- 内蔵ブラウザではダウンロードイベントを取得できなかったため、OSの保存先にファイルが作られたことは未確認。出力データ、保存用リンク（MIME・download属性）、画像プレビュー、JSON内容を確認済み。通常のブラウザで「ファイルを保存」を使う。
- デスクトップの複数ブラウザ・複数OSの網羅テストは未実施。
- フォントはシステムフォント参照で、SVGの別端末での字形一致は保証しない。
- Blender、複数配列、複数タブ同時編集は対象外。

## M4.1検証（2026-09-27）

- 自動テスト14件成功。61キーのmm位置・外形幅、行形状、長尺キーの奥行き維持、有限メッシュ、インデックス、上向き法線、UVの向き・範囲、共通日本語・Novelty描画を含む。型チェック・本番ビルド成功。
- macOSの内蔵ブラウザで61/61キーの描画、日本語「喫茶」「温」、星Novelty、配色をPNGプレビューで確認。上面・斜め・照明・サテン切替を操作。
- 4案比較の上面／照明を一括変更し、1案のドラッグで他案の視点が同時に変わることを確認。
- 3D PNGのバイナリを確認：2844×1293px、845092 bytes。別設定の2844px出力は約101ms（単発測定、FPSや他端末性能の保証ではない）。

- 実GPUの故障・コンテキスト喪失の強制試験と複数GPU横断の性能測定は未実施。ダウンロードのOS保存先確認の制約は上記と同じ。
